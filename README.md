# WilloBarber 💈

Application mobile de réservation pour un salon de coiffure unique à Bruxelles.

## Structure du projet

- `backend/` — API Django REST Framework
- `mobile/` — Application mobile Expo / React Native
- `dashboard/` — Dashboard coiffeur React/Vite (en cours)

## Technologies

- Backend : Python / Django / DRF
- Mobile : Expo / React Native / TypeScript
- Dashboard : React / Vite (à venir)
